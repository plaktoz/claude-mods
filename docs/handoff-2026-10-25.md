## Still open: the mods

Each item is a known limit or a finding that is not fixed. Fix one only when the user asks.

- **brain-dump:** `isQuestion` checks `Array.isArray(options)` but not the 2 to 4 string options. Cancel is treated as "send original". `Submission` re-declares `PromptSubmitInput`. Tests do not cover classify throwing, invalid options or cancel.
- **cache-warm:** the legacy-console glyph fallback is deferred, and needs a decision. A ping whose fork outlives its turn can overwrite a newer turn's expiry or tokens. `maxPings` from `Number(...)` can be NaN.
- **handoff:** a dropped handoff does not reset `lastTurnEnd`. WebFetch URLs go unfiltered into the clipboard text. The README hardcodes line numbers. The offer path has no test.
- **screen-share:** the PHONE regex over-masks plain figures. CJK names in unspaced text are missed. Suffix currency (`5€`) is missed. `bar` has no `u` flag. `deepMask` masks values, not keys. Question and label stay unmasked by design.
- **switchboard:** `CLAUDE_CONFIG_DIR` is ignored. The poll interval (`$.clock.every`, line 191) has no `catch`. `refresh` concurrency is not guarded. Only `~/.claude/*` is watched. `claude.cmd` shim spawn is unverified. Recheck "No mods installed" shown when a lookup fails.
- **theme-cli:** sound on Windows (`afplay`) is deferred, and needs a decision. The module-level `loop` AbortController is lost on hot reload. `bun test` fails: use `claude plugin test`. Half-blocks and truecolour on legacy conhost are unverified. Three long sentences remain in README.md (lines 269, 274, 631). `register.tsx` is large and has some duplication.
- **theme-desk:** KIV. See `mods/theme-desk/README.md`. Do not work on it unless the user asks.
