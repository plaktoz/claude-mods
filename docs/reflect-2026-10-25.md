# Task list: the `reflect` mod, 2026-10-25

Status: T1 done (scaffold). T2 to T6 open.

Goal: a new mod, `mods/reflect/`. It watches the prompts you type. When a prompt states a lasting rule, it shows a pop-up and asks where to save the rule. This gives you control over what is saved for good and what stays temporary, on top of the native auto-memory of Claude Code.

Source: a transcript summary of the "Reflect mod" (video, 08:54 to 09:49). It describes a background listener that parses every prompt, detects a hard rule, and shows a pop-up with storage choices. Examples of rules from the source:
- Aesthetic: "never use m-dashes".
- Structural: "keep LinkedIn hooks under 12 words".
- Procedural: a mandate about how to do the work.

Storage choices in the source: the built-in memory of Claude Code, a local `claude.md` or `agent.md` file, and a personal Second Brain database. The source also says you can ask Claude to change where the mod saves.

State key: `[ ]` open, `[x]` done, `[-]` not done (reason given).

## Decisions (confirmed by the user, 2026-10-25)

1. **Detection.** A cheap cue-word check runs first (for example: always, never, from now on, must, keep, make sure, do not). Only a prompt with a cue word goes to haiku. Haiku confirms that the prompt holds a lasting rule and writes the rule in one line.
2. **Timing.** The prompt is sent at once. The pop-up appears after Claude's reply, at `turn.complete`. The mod never holds a prompt.
3. **Destinations on by default.** Auto memory and the project `CLAUDE.md`.
4. **Destinations off by default.** The global `~/.claude/CLAUDE.md` (the user can switch it on). Second Brain (needs a folder path and a file format from the user).
5. **Location.** `mods/reflect/`, like the other mods. The `plugin-authoring` skill suggests a scratch folder under `~/.claude/dev-mods/`. Do not use it.
6. **Commits.** The user asked for commits on this work. Commit after each task, or each group of tasks that belong together. Do not push until the user approves.

## Defaults picked by the agent (change on request)

- The mod asks about at most 1 rule per prompt.
- Closing the pop-up saves nothing.
- A rule that is already saved, or that the user skipped in this session, is not asked about again.
- A failed model call or a failed write is silent and saves nothing, as in `brain-dump`.
- Only prompts typed in the prompt box are watched (`origin.kind` is `composer`). Commands, meta messages and prompts from plugins, peers or the SDK are ignored, as in `brain-dump`.
- The pop-up (`$.ui.ask`) takes at most 4 options. It offers the enabled destinations (at most 3) and one skip option. The destinations are settings, so the user changes them with `userConfig` and not with the pop-up.

## Design

- `prompt.submit` records the prompt text when it passes the origin rules and has a cue word. It returns at once.
- `turn.complete` takes the recorded prompt. `$.model.classify` with haiku decides rule or not. `$.model.complete` with haiku words the rule in one line.
- `$.ui.ask` shows the rule and the destinations.
- Writers use `$.fs`. Each writer reads the file first, skips a duplicate, then writes.
  - Auto memory: a feedback file in the project's memory folder, plus one line in `MEMORY.md`.
  - Project and global `CLAUDE.md`: append the rule under a `## Rules` heading.
  - Second Brain: one file in the configured folder.
- `userConfig` fields: `destinations`, `secondBrainPath`, `cues`.
